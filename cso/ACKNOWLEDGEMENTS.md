# Teşekkürler

/cso v2, güvenlik denetimi alanındaki araştırmalardan esinlenmiştir. Katkıda bulunanlar:

- **[Sentry Security Review](https://github.com/getsentry/skills)** — Güvene dayalı raporlama sistemi (yalnızca YÜKSEK güven bulguları raporlanır) ve "önce araştır, sonra raporla" metodolojisi (veri akışını izle, yukarı akış doğrulamasını kontrol et), 8/10 günlük güven eşiğimizi doğruladı. TimOnWeb bunu test edilen 5 beceri arasından kurmaya değen tek güvenlik becerisi olarak değerlendirdi.
- **[Trail of Bits Skills](https://github.com/trailofbits/skills)** — Denetim bağlamı oluşturma metodolojisi (hata avlamadan önce zihinsel model oluştur) doğrudan Aşama 0'ı ilhamlandırdı. Varyant analiz kavramları (bir güvenlik açığı buldunuz mu? Tüm kod tabanında aynı deseni arayın) Aşama 12'nin varyant analiz adımını ilhamlandırdı.
- **[Shannon by Keygraph](https://github.com/KeygraphHQ/shannon)** — XBOW kıyaslamasında %96.15 başarıya ulaşan otonom AI sızma testi aracı (104 istismarın 100'ü). AI'nın gerçek güvenlik testi yapabileceğini, yalnızca kontrol listesi taraması yapmadığını doğruladı. Aşama 12 aktif doğrulamamız Shannon'ın canlı olarak yaptığının statik analiz versiyonudur.
- **[afiqiqmal/claude-security-audit](https://github.com/afiqiqmal/claude-security-audit)** — AI/LLM'ye özgü güvenlik kontrolleri (prompt enjeksiyonu, RAG zehirlenmesi, araç çağırma izinleri) Aşama 7'yi ilhamlandırdı. Çerçeve düzeyinde otomatik algılama ("Next.js"i yalnızca "Node/TypeScript" değil de algılama) Aşama 0'ın çerçeve algılama adımını ilhamlandırdı.
- **[Snyk ToxicSkills Araştırması](https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub/)** — AI ajan becerilerinin %36'sında güvenlik açığı ve %13.4'ünde kötü amaçlı yazılım olduğu bulgusu Aşama 8'i (Beceri Tedarik Zinciri taraması) ilhamlandırdı.
- **[Daniel Miessler'ın Kişisel AI Altyapısı](https://github.com/danielmiessler/Personal_AI_Infrastructure)** — Olay müdahale oyun kitapları ve koruma dosyası kavramı, düzeltme ve LLM güvenlik aşamalarını bilgilendirdi.
- **[McGo/claude-code-security-audit](https://github.com/McGo/claude-code-security-audit)** — Paylaşılabilir raporlar ve eyleme geçirilebilir destanlar oluşturma fikri, rapor formatı evrimimizi bilgilendirdi.
- **[Claude Code Security Pack](https://dev.to/myougatheaxo/automate-owasp-security-audits-with-claude-code-security-pack-4mah)** — Modüler yaklaşım (ayrı /security-audit, /secret-scanner, /deps-check becerileri) bunların farklı kaygılar olduğunu doğruladı. Birleşik yaklaşımımız, çaplar arası akıl yürütme için modülerlikten feragat eder.
- **[Anthropic Claude Code Security](https://www.anthropic.com/news/claude-code-security)** — Çok aşamalı doğrulama ve güven puanlaması, paralel bulgu doğrulama yaklaşımımızı doğruladı. Açık kaynak kodda 500+'den sıfır-gün bulgusu.
- **[@gus_argon](https://x.com/gus_aragon/status/2035841289602904360)** — Kritik v1 kör noktaları tespit etti: yığın algılama yok (tüm-dil kalıplarını çalıştırır), Claude Code'un Grep aracı yerine bash grep kullanır, `| head -20` sonuçları sessizce keser ve giriş şişirmesi. Bunlar doğrudan v2'nin yığın-öncelikli yaklaşımını ve Grep aracı zorunluluğunu şekillendirdi.
